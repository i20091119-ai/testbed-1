# ⚖️ 저울 수학 — 경남수학문화관 체험전시 웹앱

터치형 전자칠판에서 손가락으로 무게추를 끌어다 놓으며 **지렛대(모멘트) 원리**와
**자연수 사칙연산**을 함께 익히는 게임입니다.

> **모멘트 = 무게 × 거리(눈금)**
> 왼쪽 모멘트 합 = 오른쪽 모멘트 합 → 저울이 수평이 되고 정답!

화면 위쪽 수식의 네모(□)를 맞히는 것과 저울의 수평을 맞추는 것이 **같은 문제**가 되도록
설계되어 있어, 아이가 식과 저울을 오가며 원리를 스스로 발견하게 됩니다.

---

## 실행 방법

별도의 설치나 서버가 필요 없습니다.

1. `index.html` 을 더블클릭하면 브라우저에서 바로 실행됩니다.
2. 전자칠판에서는 브라우저를 **전체 화면(F11)** 으로 켜서 사용하세요.

인터넷 연결도 필요 없습니다. (외부 글꼴·라이브러리를 쓰지 않습니다)

### 웹으로 배포하고 싶다면

이 폴더(`gyeongnam-math-balance/`)를 통째로 웹 서버나 GitHub Pages 에 올리면 됩니다.

## 화면 구성

| 화면 | 내용 |
|---|---|
| **시작 화면** | 게임 시작 / 자유 탐구 / 사용법 / 설정, 최고 기록 |
| **게임 화면** | 수식 → 저울 → 추 보관함, 제한시간·점수·진행 표시 |
| **축하 화면** | 별 1~3개, 점수, 맞힌 문제, 최고 단계, 최고 기록, 색종이 효과 |

### 조작

- **추 보관함**에서 추를 손가락으로 **끌어다** 저울 눈금 위에 놓습니다.
- 놓은 추를 **톡 누르면** 보관함으로 돌아갑니다.
- 한 눈금에는 추를 **3개까지** 쌓을 수 있습니다.

### 도구 버튼

- **💡 힌트** — 1번: 어느 칸에 놓아야 하는지 알려 줌 / 2번: 양쪽 계산 값을 보여 줌 (점수 −30)
- **↺ 다시** — 놓은 추를 모두 치움
- **⏭ 넘기기** — 문제를 넘기고 정답 배치를 보여 줌

## 난이도 5단계 (문제 100개, 단계별 20문제)

| 단계 | 연산 | 거리 사용 | 놓을 추 | 수식 예시 | 제한시간 |
|---|---|---|---|---|---|
| 1 ★☆☆☆☆ | 덧셈 | ✕ (①번 칸 고정) | 1개 | `3 + 4 = □` | 45초 |
| 2 ★★☆☆☆ | 뺄셈 | ✕ (①번 칸 고정) | 1개 | `11 = □ + 4` | 50초 |
| 3 ★★★☆☆ | 곱셈·나눗셈 | ○ | 1개 | `6 × 2 = □ × 3` | 60초 |
| 4 ★★★★☆ | 혼합(2항) | ○ | 1개 | `5 × 3 + 2 × 1 = □ × 4` | 75초 |
| 5 ★★★★★ | 혼합 + 다중 배치 | ○ | 2개 | `7 × 4 + 2 × 3 = □ × 5 + 3 × 3` | 90초 |

- 1~2단계는 거리 개념이 아직 없으므로 **①번 칸만 열려** 있습니다.
- **연속으로 맞히면 단계가 올라가고**(3연속 +1단계, 5연속 +2단계),
  연속으로 틀리면 한 단계 내려갑니다.

### 점수

```
기본 100점 + 단계 × 20점 + 남은 시간 × 2점 + 연속 정답 × 10점 − 힌트 × 30점
```

## ⚙️ 설정 (선생님용)

시작 화면의 **설정** 버튼에서 바꿀 수 있고, 브라우저에 저장됩니다.

| 항목 | 선택 |
|---|---|
| 한 판 문제 수 | 5 / 10 / 15 / 20 문제 |
| 제한 시간 | 사용 / 사용 안 함 |
| 시간 여유 | ×0.7 / ×1 / ×1.5 / ×2 |
| 난이도 | 자동(점점 어렵게) / 1~5단계 고정 |
| 소리 | 켜기 / 끄기 |
| 계산 값 보여주기 | 숨기기 / 보여주기 (모멘트 값을 항상 표시) |

> 저학년 수업이라면 **난이도 1~2단계 고정 + 시간 여유 ×2** 를 권합니다.

## 그림 교체

**코드를 고치지 않고** 그림 파일만 바꾸면 됩니다.

- `assets/logo.svg` → 수학문화관 로고
- `assets/weight.svg` → 무게추 그림 (숫자는 게임이 그림 위에 자동으로 그려 줍니다)

무게마다 다른 그림을 쓰거나 PNG 를 쓰려면 `js/game.js` 맨 위 `ASSETS` 설정만 바꾸면 됩니다.

### 📄 문제 검수표 (100문제 전체)

**[`문제-검수표.pdf`](문제-검수표.pdf)** — A4 12쪽, 인쇄용

문제마다 화면에 나오는 **수식**, 저울의 **눈금별 추 배치**, **검산**(양쪽 모멘트),
**보관함 추 목록**을 함께 실었습니다. 마지막 쪽은 정답 일람표입니다.

### 문제를 직접 고치거나 추가하려면

`js/problems.js` 의 형식을 그대로 따르면 됩니다. 파일 맨 위에 각 항목 설명이 있습니다.
**왼쪽 모멘트 합과 오른쪽 모멘트 합이 반드시 같아야** 정답 처리가 됩니다.

고친 뒤에는 반드시 검사기를 돌려 주세요.

```
node tools-test-problems.js
```

21개 항목을 검사합니다 — 모멘트 일치, 등식과 저울의 항 대응, 빈칸 유일성,
보관함으로 풀 수 있는지, **수평을 만드는 방법이 정답 하나뿐인지**, 중복 문제, 난이도 구조.
문제가 있으면 어떤 문제 몇 번인지 알려 줍니다.

문제를 새로 100개 만들고 싶다면 `node tools-generate-problems.js` 를 실행하세요.
