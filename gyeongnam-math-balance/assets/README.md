# 그림 교체 안내

이 폴더의 그림만 바꾸면 게임의 모습이 바뀝니다. **코드를 고칠 필요가 없습니다.**

> 📄 **직접 그리실 때는 [`../디자인-시안집.pdf`](../디자인-시안집.pdf) 를 먼저 보세요.**
> 안전 여백·숫자 자리 같은 정확한 규격과, 인쇄해서 바로 그릴 수 있는
> **실제 크기 템플릿**(7 · 8쪽)이 들어 있습니다.

## 1. 로고 바꾸기

`logo.svg` 를 준비하신 로고 파일로 덮어쓰기 하세요.

- 권장 비율: 가로로 긴 형태 (약 3 : 1)
- 배경이 투명한 파일(PNG·SVG)을 쓰면 가장 예쁩니다.

**PNG·JPG 로 바꾸고 싶다면?**
그림 파일을 이 폴더에 넣고 (`logo.png`), `js/game.js` 맨 위의 설정에서 경로만 바꿔 주세요.

```js
const ASSETS = {
  logo:   'assets/logo.png',   // ← 여기
  ...
};
```

## 2. 무게추 그림 바꾸기

`weight.svg` 를 준비하신 추 그림으로 덮어쓰기 하세요.

- 권장 비율: **정사각형 (1 : 1)**
- **숫자는 게임이 그림 위에 자동으로 그려 줍니다.** 그림 가운데는 숫자가 잘 보이도록
  밝게 비워 두시는 편이 좋습니다.
- 배경이 투명한 파일을 권장합니다.

### 무게마다 다른 그림을 쓰고 싶다면

`js/game.js` 맨 위 설정에서 무게별 그림을 지정할 수 있습니다.
지정하지 않은 무게는 기본 그림(`weight.svg`)을 사용합니다.

```js
const ASSETS = {
  weight: 'assets/weight.svg',

  weightByValue: {
    1: 'assets/w1.png',
    2: 'assets/w2.png',
    // ... 필요한 무게만 적어도 됩니다
  },

  // 기본 그림 한 장의 색조를 무게마다 자동으로 바꿔 알록달록하게 보여 줍니다.
  // 직접 그린 그림을 쓸 때는 false 로 바꿔 주세요.
  tintByValue: true,
};
```

> 게임에 나오는 추의 무게는 **1 부터 12 까지**입니다.

## 3. 주의

- 그림 파일 이름과 `js/game.js` 의 경로가 정확히 일치해야 합니다. (대소문자 구분)
- 그림을 못 찾으면 게임이 멈추지 않고 **기본 모양**으로 대신 그립니다.
  화면에 추가 밋밋한 분홍 도형으로 보인다면 파일 경로를 확인해 주세요.
- 그림을 바꾼 뒤에도 예전 그림이 보이면 브라우저에서 **새로고침(Ctrl+F5)** 해 주세요.
