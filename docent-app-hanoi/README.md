## 만든 의도 · 쓰이는 장면

1. **의도** — 해설강사가 없을 때도 관람객이 혼자 하노이탑의 규칙을 찾도록, 설명보다 "세어 보기 → 예측하기 → 확인하기"를 먼저 두었다.
2. **장면** — 관람객이 전시물 옆 QR을 찍고, 원판을 옮길 때마다 휴대폰의 +1을 눌러 1·3·7번을 직접 확인한다.
3. **장면** — 같은 화면을 저학년은 "두 번 더하고 1 더하기", 고학년은 2ⁿ − 1로 읽고, 원판 4개 질문을 실물로 풀어 본 뒤 답을 연다.

## 다른 전시물로 바꾸는 방법

`index.html` 맨 위 `const EXHIBIT = { ... }` 객체만 고치면 된다.

| 키 | 내용 |
|---|---|
| `code`, `name`, `location`, `museum` | 전시물 번호·이름·위치·기관 |
| `steps` | 사용 방법 (3개 이내) |
| `counter` | 횟수 세기 제목·안내 (필요 없으면 HTML의 [2] 섹션 삭제) |
| `levels.low.html`, `levels.high.html` | 저학년·고학년 설명 (두 내용이 서로 달라야 함) |
| `quiz` | 질문, 선택지, 정답 번호(`answerIndex`, 0부터), 해 보기 안내, 풀이 |
| `faq` | 자주 묻는 질문 3개 `{ q, a }` |

그림은 HTML 안의 `<svg class="diagram">` 하나다. 다른 전시물이면 지우거나 바꾼다.
