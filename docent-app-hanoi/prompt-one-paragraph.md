# 한 문단 요청 예시

Claude 채팅에 아래 한 문단을 그대로 붙여 넣으면 이 폴더의 `index.html`과 같은 형태의 앱이 나온다.

> 경남수학문화관 어드벤처관 1층의 A-19 대형 하노이탑을 설명하는 휴대폰용 도슨트 웹앱을 HTML 한 파일로 만들어 줘. 사용 방법은 3단계 이내, 수학 원리는 초등 저학년과 고학년 두 단계로 나눠 쉬운 말로 써 줘. 고학년은 최소 이동 횟수 1, 3, 7, 15의 규칙과 2ⁿ−1까지. '원판 4개면 몇 번?' 생각 질문은 관람객이 먼저 고른 뒤 답을 보게 하고, 자주 묻는 질문 3개와 답, 옮긴 횟수를 세는 버튼도 넣어 줘. 글씨는 크게, 휴대폰 한 화면에.

## 받은 뒤 확인할 것
- 수학 숫자: 1, 3, 7, 15, 31 / 2ⁿ − 1
- 답 보기 전에 정답이 보이지 않는지
- 저학년·고학년 탭 내용이 실제로 다른지
- 휴대폰에서 글씨가 작거나 옆으로 넘치지 않는지
