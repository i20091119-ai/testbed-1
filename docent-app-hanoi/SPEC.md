## 0. 목적

- 해설강사 연수 1일차(2026.11.10) "도슨트 앱" 활동의 **완성 예시**

## 4. 기술 조건

- **HTML 파일 1개** (`index.html`), CSS·JS 내장, 외부 라이브러리·빌드 없음
  - 해설강사가 Claude 채팅에서 만드는 결과물과 같은 형태여야 비교 가능
- 오프라인 동작, 시스템 폰트(`-apple-system, "Apple SD Gothic Neo", "Noto Sans KR", sans-serif`)
- 세로 360~430px 기준, 가로 스크롤 없음
- 본문 17px 이상, 버튼 터치 영역 44px 이상
- 첫 화면(스크롤 없이): 전시물 이름, 위치, 사용 방법 3단계
- 수준 기본값 "저학년", 저장 기능 없음
- 그림은 **인라인 SVG** 1개: 기둥 3개 + 원판 3개 단순 도식
- 내용은 HTML 상단 데이터 객체 하나(`const EXHIBIT = {...}`)에 모아 다른 전시물로 교체 쉽게
- 배포 선택: GitHub Pages → `qr.png` 생성

## 6. 내용 초안

> 문장은 초안. 수학 정확성 유지, 실제 전시물 상태에 맞게 다듬을 것.

### 사용 방법 (3단계)
1. 원판은 한 번에 1개, 맨 위에 있는 것만 옮겨요.
2. 큰 원판은 작은 원판 위에 올릴 수 없어요.
3. 원판 1개, 2개, 3개… 늘려 가며 다른 기둥으로 모두 옮기고, 몇 번 옮겼는지 세어 봐요.

### 수학 원리
- **저학년**
  - 원판 1개는 1번, 2개는 3번, 3개는 7번이면 옮길 수 있어요.
  - 1, 3, 7… 숫자가 커지는 데 규칙이 있어요. 앞의 수를 두 번 더하고 1을 더하면 다음 수가 돼요. (1+1+1=3, 3+3+1=7)
  - 이렇게 숫자가 늘어나는 규칙을 찾는 것이 수학이에요.
- **고학년**
  - 원판 n개를 옮기려면: ① 위의 n−1개를 가운데 기둥으로 ② 가장 큰 원판 1개를 목표 기둥으로 ③ n−1개를 다시 그 위로.
  - 그래서 (n개 횟수) = 2 × (n−1개 횟수) + 1 → 1, 3, 7, 15, 31, …
  - 각 수에 1을 더하면 2, 4, 8, 16, 32 — 2를 거듭 곱한 수. 그래서 최소 횟수는 **2ⁿ − 1**.
  - 더 알아보기(접기, 중·고등): 앞의 경우가 맞으면 다음 경우도 맞다는 방식으로 모든 n에서 성립함을 보이는 것이 '수학적 귀납법'(고등 수학Ⅰ).

### 생각 질문
- 질문: "원판이 4개면 최소 몇 번 옮겨야 할까?"
- 선택지: ① 8번 ② 15번 ③ 16번
- 버튼 "직접 해 보고 답 보기" → 답: **15번**. 3개(7번)를 옮기고, 가장 큰 원판 1번, 다시 3개(7번). 7 + 1 + 7 = 15.

### 자주 묻는 질문
1. **하노이탑은 누가 만들었어요?** — 1883년 프랑스 수학자 에두아르 뤼카가 만든 퍼즐이에요. 64개 원판을 옮기면 세상이 끝난다는 이야기도 함께 지어 붙였어요.
2. **64개를 옮기면 얼마나 걸려요?** — 2⁶⁴ − 1번, 약 1,800경 번이에요. 1초에 1번씩 옮겨도 약 5,800억 년이 걸려요.
3. **기둥이 4개면 더 빨라져요?** — 네. 원판 3개는 기둥 3개일 때 7번, 기둥 4개일 때 5번이면 돼요. 기둥이 4개일 때 최소 횟수를 구하는 방법은 오래 풀리지 않던 문제였어요.

## 7. 정확성 확인 목록 (생성 후 반드시 검토)

- [ ] 최소 횟수 1, 3, 7, 15, 31 / 일반식 2ⁿ − 1 / 점화식 aₙ = 2aₙ₋₁ + 1
- [ ] 저학년 설명 "두 번 더하고 1 더하기" 계산 예가 맞는지
- [ ] 뤼카 1883년
- [ ] 2⁶⁴ − 1 = 18,446,744,073,709,551,615 ≈ 1,844경 → "약 1,800경"; 1초 1번 ≈ 5,845억 년 → "약 5,800억 년"
- [ ] 기둥 4개: 원판 3개 최소 5번, 4개 9번, 5개 13번 (Frame–Stewart). 일반 증명은 2014년(Bousch) — 앱에는 "오래 풀리지 않던 문제" 수준으로만
- [ ] 전시물 실제 원판 수·시작 상태와 사용 방법 문구 일치
