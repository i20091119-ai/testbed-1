# ♞ 기사의 여행 (5×5 나이트 투어)

경상남도교육청 **경남수학문화관** 학급 전자칠판용 웹앱 — 균형 저울 게임에 이은 두 번째 앱입니다.

`knight/index.html` 을 브라우저로 열면 바로 실행됩니다. 서버·설치·인터넷 연결이 필요 없습니다.

## 화면 흐름

```
인원 선택(1~4인) → 규칙 안내 → 시작하기 → 카운트다운(3-2-1) → 게임(2분) → 결과·메달
```

균형 저울 게임과 같은 흐름·서체·효과음·좌상단 로고를 그대로 씁니다.

## 게임 규칙

| 항목 | 규칙 |
|---|---|
| 판 | 5×5 체스판, 나이트는 ㄱ자(L자)로만 이동 |
| 인원 | 1~4인. 고른 인원수만큼 화면이 세로로 나뉘고 **각자 자기 보드에서 동시에** 진행 |
| 시간 | 전원 공용 **2분** (한 개의 타이머) |
| 점수 | 새 칸을 밟을 때마다 **10점** |
| 완주 보너스 | 25칸을 모두 돌면 **+100점** (한 바퀴 만점 350점) |
| 완주 후 | 보드가 비워지고 **점수는 그대로 둔 채** 새 보드로 다시 도전 (2분 안에 여러 바퀴 가능) |
| 출발 칸 | 학생이 **아무 칸이나 눌러서** 자유롭게 선택 |
| 못 가는 칸 | 칸이 빨갛게 흔들리고 오답음만 — **감점 없음** |
| 되돌리기 | 언제나 가능. 직전 한 칸을 무르고 **그 칸의 10점도 함께 되돌림** |
| 새로 시작 | **막혔을 때만** 눌립니다. 보드만 비우고 **점수는 유지** |
| 순위 | 시간이 끝나면 점수순 🥇🥈🥉, **동점은 공동 순위** |

### 왜 되돌리기는 점수를 되돌리나요

되돌리기가 점수를 남겨두면 같은 칸을 무르고 다시 밟는 것만으로 점수를 무한히 벌 수 있습니다.
점수를 "지금 밟고 있는 칸 수"에 정확히 대응시키기 위해 되돌린 칸의 10점은 회수합니다.
반대로 **새로 시작**은 막다른 길에 갇힌 학생만 쓸 수 있으므로 점수를 그대로 두어도 안전합니다.

### 알아두면 좋은 수학

5×5 판에서는 **출발 칸에 따라 25칸 완주가 아예 불가능**합니다.
체스판 색으로 나누면 모서리와 같은 색인 13칸에서 출발할 때만 완주할 수 있고,
나머지 12칸에서 출발하면 아무리 잘 두어도 끝까지 갈 수 없습니다.
앱은 이를 미리 알려주지 않습니다 — 학생이 직접 부딪혀 보고 "왜 어떤 칸은 안 될까?"를
발견하는 것이 이 놀이의 핵심입니다.

## 조작

| 버튼 | 하는 일 |
|---|---|
| ❓ | 게임 방법 다시 보기 |
| ⏸ | 선생님용 일시정지 (이어서 하면 3-2-1 카운트다운 후 재개) |
| 🔊 | 효과음 켜기/끄기 (선택이 기기에 저장됨) |
| 🏠 | 처음 화면으로 |

- 여러 명이 **동시에 터치해도** 각 보드가 독립적으로 반응합니다(멀티터치).
- 같은 보드에서 **3번 연속** 못 가는 칸을 누르면 갈 수 있는 칸을 3초간 살짝 표시합니다.

## 저울 균형 웹앱에서 그대로 가져온 것

| 항목 | 출처 |
|---|---|
| 좌상단 로고 | `assets/logo.png` |
| 서체 | `assets/fonts/Sunflower-Bold.ttf` (썬플라워 B, SIL OFL — 상업·전시 사용 무료, 라이선스 동봉) |
| 효과음 | `js/audio.js` — WebAudio 합성음, 음원 파일·네트워크 불필요 |
| 축하 연출 | `js/confetti.js` |
| 화면 흐름·버튼·색·1920×1080 자동 배율 | `css/style.css` |

효과음에는 기사의 여행 전용으로 `step`(착지) · `undo` · `reset` · `stuck`(막힘) · `tour`(완주) ·
`countdown` 을 더했습니다.

## 그림 갈아끼우기

기본 그래픽은 전부 코드로 그려져 있지만, 정해진 이름으로 그림을 넣으면 **코드를 고치지 않아도
그 부분만 자동으로 교체**됩니다. 일부만 넣어도 되고, 파일을 지우면 원래 그래픽으로 돌아옵니다.

**→ 크기·투명도·배치도까지 담은 전체 명세: [`docs/이미지_에셋_명세서.pdf`](docs/이미지_에셋_명세서.pdf)**

| 폴더 | 파일 | 바뀌는 곳 |
|---|---|---|
| `assets/ui/` | `bg-start · bg-rules · bg-game · bg-result.png` | 화면 4개의 배경 |
| `assets/ui/` | `title.png` | 시작 화면 제목 (넣으면 글자 제목이 숨겨짐) |
| `assets/ui/` | `howto-1~4.png` | 규칙 안내 카드 4장 (카드 통째로) |
| `assets/ui/` | `cell-light.png · cell-dark.png` | 체스판 밝은 칸 · 어두운 칸 |
| `assets/ui/` | `panel.png` | 플레이어 보드 패널 바탕 |
| `assets/ui/` | `medal-1~3.png` | 결과 화면 금·은·동메달 |
| `assets/pieces/` | `knight-1~4.png` | 플레이어별 나이트 말 |

두 폴더는 아직 없습니다. 직접 만들어 넣고 브라우저를 강력 새로고침(`Ctrl+Shift+R`)하면 반영됩니다.

## 파일 구성

```
knight/
├── index.html          화면 4개(인원 선택 / 규칙 / 게임 / 결과) + 팝업
├── css/style.css       디자인 토큰과 레이아웃
├── js/app.js           게임 본체 (규칙·타이머·순위)
├── js/audio.js         효과음
├── js/confetti.js      결과 화면 색종이
├── docs/               이미지 에셋 명세서(PDF)
└── assets/             로고 · 서체 (+ 넣으면 적용되는 ui/, pieces/)
```

## 화면 크기

1920×1080 기준으로 만들고 화면 비율에 맞춰 자동으로 배율을 조정합니다.
전자칠판, 노트북, 태블릿 어디서든 여백 없이 꽉 차게 표시됩니다.
